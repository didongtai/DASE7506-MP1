## 发现的问题和提交缺项

### 1. 长度为 1～3 的输入会抛出 KeyError

`student.py` 的 `_general_ngram_log_probs` 在高阶 n-gram 的上下文长度超过输入长度
时提前 `continue`，没有初始化 `standard_found_by_order` 等后续会访问的条目。
真实 v5 对长度 1、2、3 的输入分别报 `KeyError: 3/4/5`；长度 4、12 可以运行。

原始评分器的 `common.windows` 将所有输入（包括最后一个短窗口）补齐为 256，
所以此问题不影响当前完整测试集分数，但模型短前缀接口仍需修复。现有 11 项测试
全部通过，因为它们没有覆盖加载完整 n-gram checkpoint 后的这个分支。
本次核查保留了冻结版本；若修复，需要更新源码哈希并重新做回归核验。

### 2. 训练成本原说明漏算了平均分支，现已更正

checkpoint 的 `train_tokens=245,760,000` 是沿一条路径继承的计数，不能代表
所有参与权重平均的分支成本。按复现命令和每次运行的 `run_train_tokens` 去重求和：

- 复制训练之前：19 次训练、**186,777,600** 个目标，而非路径计数 147,456,000。
- 最终选中模型的完整训练祖先：21 次训练、**285,081,600** 个目标；训练时间合计 8,993.12 秒。
- 当前保存的全部 70 次训练记录：**719,667,200** 个目标；训练时间合计 12,717.42 秒。

已修正 EXPERIMENTS.md。没有改写已冻结 checkpoint 中的旧计数；报告必须区分两种口径。
总时间是不同 CPU/GPU 运行的训练秒数之和，不含数据准备、验证、校准或未记录的尝试，
也不是整个项目的实际历时。详细种子、继承路径及每次成本见 [run-costs.json](audit/v5/run-costs.json)。

### 3. 正式报告和不可变发布链接尚未齐备

本地未发现要求的、包括图表和参考文献在内最多 10 页的正式报告。
EXPERIMENTS.md 已有方法、对照、消融、成本及复现命令，但还需要整理成可确认页数的报告。
本次未核验已发布的不可变代码 URL、匹配 checkpoint 的下载 URL 或课程网站提交状态。
`runs/` 和 `*.pt` 被 Git 忽略，不能只上传代码就认为模型也已提供。

### 4. 对历史测试集使用情况不能作过度保证

v5 的校准文件声明 `split=validation`；对应脚本只使用验证集选择温度、混合权重
和缓存门控参数。最终 checkpoint 的神经张量与记录的训练父模型一致，表张量与训练集重建一致。
此次重复测试仅核验冻结模型的分数和资源，没有据此选择新模型。

但现存记录显示旧候选模型也曾运行公开 test，之后仍继续了开发。以下时间由现存
文件修改时间转换为 UTC+8，仅作为辅助证据，不是不可篡改的执行日志：

| v3 测试 | 9 月 28 日 21:32 | test BPB 1.552751025 |
| v4 测试 | 9 月 29 日 11:44 | test BPB 1.551456326 |
| 新增复制训练阶段 1 完成 | 9 月 29 日 17:04 | 又处理 49,152,000 个训练目标 |
| 新增复制训练阶段 2 完成 | 9 月 29 日 17:12 | 又处理 49,152,000 个训练目标 |

在“所有开发使用 validation、测试前冻结方法”的严格要求下，已有流程存在实质性问题。
目前未发现把 test 目标直接传入训练损失或 v5 校准脚本的证据，但这不足以证明此前
test 反馈没有影响后续决策。最终 v5 的标量通过 validation 选择，也不能追溯消除
此前看到 test 后继续开发所产生的争议。

已收窄 EXPERIMENTS.md 开头原先过于绝对的描述。应向教师如实说明这一过程，请其
判定当前提交是否可接受；不能由本地自动检查代替该判断。证据见
[test 与继续开发记录](audit/v5/test-development-history.json)。

### 5. 早期开发脚本存在不应开放的 test 搜索选项，现已限制

早期 `experiments/cache_sweep.py` 的默认值虽为 validation，但原先允许传入
`--split test`，随后对多组缓存参数排序。这不是冻结模型的单次复现接口，若使用
test 搜索会违反开发划分规则。没有找到本次 v5 使用该选项的记录，其简单频率缓存
也未采用到 v5。现已将该脚本限制为 validation；命令行指定 test 会在加载数据前拒绝。
这是预防后续误用的修正，不是对历史流程争议的补救。

### 6. 训练继承链的额外核查

遍历最终组装、复制训练初始化、继续训练、扩层和权重平均的 29 个 checkpoint 节点，
全部可解析到本地 `large-1200-s17` 随机初始化训练记录。保留的训练 metrics 中的
checkpoint 哈希及记录的父模型哈希全部匹配，没有未解析父节点或外部模型路径。
当前训练代码仅对 train tokens 计算参数更新，验证仅用于评测与明确的标量校准。
这为自训练来源提供了文件级证据，但没有重跑完整训练，也不能证明历史决策未受 test 影响。
详见 [lineage-review.json](audit/v5/lineage-review.json)。
